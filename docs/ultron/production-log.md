- **What was built:**
  - **Scroll engine (smooth, tick-cadenced):** `released` counts rows released for scroll (each `onRowTick()` = one row born); `scrollRows` is the smooth position with speed law `ROWS_PER_SECOND × (SCROLL_BASE_GAIN + LAG_CATCHUP_GAIN × min(lag, LAG_CATCHUP_MAX))`, never overshooting the target (overshoot would open an empty band above the newest row). The 4% slow-bias keeps ~0.16 rows of equilibrium lag so per-frame motion is almost strictly monotonic (the clamp can only micro-stall when the driver clock jitters late — invisible at 2.5 rows/s); the proportional catch-up heals real lag (frame gaps, fast clocks) by equilibrating instead of accumulating. Row i draws at y = (scrollRows − i − 1)·cell: new rows slide IN from the top edge across one tick interval, older rows glide down and dim. Pause (no ticks) freezes both for free. Per-frame self-sync `released = max(released, CA.rowIndex + 1)` makes a forgetful driver harmless (documented warning: lookahead drivers must call onRowTick at VISUAL fire time, not schedule time — T-AVBIND owns that wiring).
  - **Glow rendering:** one luminous cell sprite pre-rendered per layout on an offscreen canvas (three shadowBlur passes: wide faint halo, inner halo, luminous core — all OFF the frame path); the frame loop only blits sprites with `globalCompositeOperation = "lighter"` (luminous accumulation) — no per-cell shadow work in rAF. Per-row alpha fade (full brightness through 55% of viewport height, dimming to 0.30 at the bottom) gives depth and makes the top the legible "now" for T-AVBIND. Palette strictly from `CANVAS_BACKGROUND`/`CELL_COLOR` in [1] (hex → rgba helper).
